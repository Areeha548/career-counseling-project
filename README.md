# Career Counseling Project

## Project overview

Career Counseling Project is planned as an AI-powered career mentor web application. It will help users explore career options, understand skill requirements, and plan practical next steps toward career goals.

## Planned features

These are future goals; this foundation step does not implement them.

- Career guidance tailored to a user's interests, skills, and goals
- AI-assisted career exploration and recommendations
- Learning resources and course suggestions
- Personalized career roadmaps and progress planning
- A straightforward web experience for users

## Planned technology stack

- **Frontend:** React and JavaScript
- **Backend:** Python with FastAPI
- **AI:** OpenAI API integration (planned)
- **Version control:** Git and GitHub

The stack may be refined as the project develops. No application code or dependencies have been added yet.

## Project structure

- `frontend/` — reserved for the future React application
- `backend/` — reserved for the future Python API
- `docs/` — project notes and documentation
